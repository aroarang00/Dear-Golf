Dear Golf 개인정보처리방침

시행일 · 2026-05-26

Dear Golf(이하 "회사")는 개인정보 보호법(이하 "PIPA")에 따라 회원의 개인정보를 다음과 같이 처리합니다.

제1조 (수집 항목 및 목적)

1. 카카오 로그인 시 수집되는 항목 (필수) - 카카오 고유 ID(sub), 닉네임, 프로필 이미지 URL - 생년월일(만 19세 이상 확인 목적) 2. 회원이 직접 입력하는 항목 (선택) - 본명, 평균 타수, 라이프 베스트 스코어, 프로필 사진 3. 서비스 이용 과정에서 자동 생성되는 항목 - 라운딩 기록, 모집 참여 이력, 매너 평가, 신뢰등급, 신고 이력 - 기기 식별자, 푸시 토큰, 접속 로그

제2조 (보유 및 이용 기간)

1. 회원 탈퇴 시까지 보유하며, 탈퇴 시 즉시 완전 삭제됩니다. 2. 예외적으로 다음 항목은 별도 기간 보존됩니다: - 영구 정지 회원의 카카오 고유 ID(sub)와 정지 사실: 영구 보존(재가입 차단 목적) - 미성년 사후 해지 회원의 카카오 고유 ID(sub): 만 19세 도달 시점까지 한정 보존 후 자동 파기 - 일반 모집글: 1년 - 분쟁 이력이 있는 모집글: 3년 - 신고 이력 및 매너 평가 이력: 3년 - 매너 평가 카운트: 12개월(자동 -1)

제3조 (제3자 제공)

회사는 회원의 동의 없이 개인정보를 제3자에게 제공하지 않습니다. 다음 경우에 한해 예외적으로 제공됩니다: 1. 회원이 사전에 동의한 경우 2. 법령에 따라 수사기관 등의 요청이 있는 경우

제4조 (개인정보 처리 위탁)

회사는 서비스 제공을 위해 다음과 같이 개인정보 처리를 위탁합니다: - 카카오: 카카오 OIDC 인증 - Google Firebase: 회원 인증, 데이터 저장(Firestore), 파일 저장(Storage), 자동 처리(Cloud Functions) - SendGrid 또는 Gmail SMTP: 신고 처리 알림 이메일 발송

제5조 (회원의 권리)

회원은 개인정보 보호법 제35조에 따라 다음 권리를 행사할 수 있습니다: 1. 열람 권리 — 마이페이지에서 직접 확인 2. 정정·삭제 권리 — 마이페이지에서 직접 처리 3. 처리 정지 권리 — 마이페이지에서 직접 처리하거나 deargolf.official@gmail.com로 요청 (접수 후 10일 이내 처리) 4. 데이터 다운로드 권리 — deargolf.official@gmail.com로 요청 (접수 후 10일 이내 처리) 5. 회원 탈퇴 권리 — 마이페이지 → 계정 탈퇴

제6조 (안전성 확보 조치)

회사는 회원 개인정보 보호를 위해 다음 조치를 취합니다: - 비밀번호 암호화(카카오 OIDC 토큰 활용, 평문 저장 X) - Firestore 보안 규칙 적용 - 외부 통신 SSL 암호화 - 접근 권한 통제

제7조 (만 14세 미만 아동 처리)

본 서비스는 만 19세 이상만 가입할 수 있으므로 만 14세 미만 아동의 개인정보는 수집하지 않습니다.

제8조 (개인정보 보호 책임자)

- 책임자: Dear Golf 운영팀 - 연락처: deargolf.official@gmail.com - 개인정보 침해 신고: 한국인터넷진흥원(국번없이 118, privacy.kisa.or.kr)

제9조 (방침 변경)
