자동 패널티 시스템 동의서

시행일 · 2026-05-26

Dear Golf는 회원 간의 약속과 신뢰를 보호하기 위해 자동 패널티 시스템을 운영합니다. 가입 시 본 시스템에 동의해주세요.

1. 자동 패널티 발동 사유

다음 사유로 매너점수 차감 및 모집·참여 정지가 자동 발동됩니다: - 노쇼 확정: 매너 -20, 60일 정지 - 허위 노쇼 신고 확정: 매너 -20, 90일 정지 - D-7 이내 참여 취소: 매너 -5(정지 없음) - 콘텐츠 신고 확정 누적: 매너 -5, 누적 시 정지

2. 영구 정지

다음 경우 영구 정지가 자동 발동됩니다: - 노쇼 또는 허위 신고 12개월 내 2회 누적 - 콘텐츠 신고 확정 12개월 내 10회 누적 - 형사 범죄 확정 판결

3. 자동 처리 면책 원칙

회사의 검토 기한(SLA) 초과 시 시스템은 자동으로 다음과 같이 처리하여 처리 지연으로 인한 회원 불이익을 방지합니다: - 노쇼 소명 48시간 무판정 → 중립 종결 (양쪽 패널티 없음, 신고자·피신고자 모두 영향 없음) - 사용자 신고 7일 무판정 → 자동 종결 (양쪽 영향 없음) - 콘텐츠 신고 3일 무판정 → 자동 거부 (게시물 영향 없음)

4. 매너점수 자연 회복

- 라운딩 정상 완료 시 +2점 - 동반자 긍정 평가(👍) 시 +1점 - 시간 경과에 따른 자동 회복

5. 정지 상태 범위

- 신규 모집글 작성 금지 - 신규 참여 신청 금지 - 이미 확정된 라운딩은 정지와 무관하게 진행(다른 참여자 보호)

6. 회원의 권리

- 모든 자동 처리 결과는 마이페이지에서 확인할 수 있습니다. - 매너 등급은 등급명(매너왕/좋음/보통/주의)으로만 표시되며 정확한 점수는 비공개입니다. - 부당하다고 판단되는 경우 소명 또는 이의 절차를 이용할 수 있습니다.
