# 홈 스토어 광고 운영 가이드 (config/storeAds)

홈 하단 한줄메모/골퍼코멘트 캐러셀에 붙는 상품 광고. **앱 업데이트 없이** Firebase 콘솔에서 문서만 고치면 전체 사용자에게 즉시 반영된다.

## 광고 올리기 / 바꾸기

1. [Firebase 콘솔](https://console.firebase.google.com/project/dear-golf/firestore) → Firestore → `config` 컬렉션 → `storeAds` 문서
2. `ads` 배열 필드를 수정 (최대 2개 노출, 3개 이상 넣어도 앞 2개만):

```
ads: [
  {
    tag:   "라운딩 준비물",              // 카드 상단 작은 라벨 (비면 '라운딩 준비물')
    title: "쿨토시 · 여름 필드 필수템",   // 본문 한 줄 (필수 — 없으면 그 광고는 무시됨)
    img:   "https://...jpg",            // 카드 전체를 채우는 사진 (선택, https만. 비면 페일스카이 단색 카드)
    url:   "https://smartstore..."      // '보러 가기' 링크 (선택, https만. 비면 앱의 STORE_URL로 폴백)
  },
  ...
]
```

## 광고 내리기

- `ads`를 빈 배열 `[]`로 → 캐러셀이 광고 없는 원래 모습으로 복귀.

## 안전장치 (앱 쪽에 이미 구현됨)

- 문서가 없거나, 읽기 실패하거나, 형식이 잘못돼도(타입 오류 등) **광고만 안 나올 뿐 앱은 정상 동작**.
- `title` 없는 항목은 무시. `img`/`url`은 https가 아니면 무시(단색 카드/STORE_URL 폴백).
- 이미지 URL이 죽어도 어두운 배경+글자는 정상 표시.
- 규칙: 로그인 사용자 읽기 전용, 클라이언트 쓰기 전면 차단(콘솔/Admin만) — 회귀 테스트 있음.

## 이미지 팁

- 가로로 긴 사진이 잘 맞음(카드가 와이드). 스마트스토어 상품 이미지 URL 그대로 써도 됨.
- 자체 호스팅이 필요하면 Firebase Storage에 올리고 다운로드 URL 사용.

## 출시 전 상태

- `ads: []` (광고 숨김)으로 두고 출시. 스토어 오픈 후 채우면 됨.
- dev에서 미리 보려면 문서에 광고를 넣고 앱 리로드 (2026-07-03 실기기 검증 완료).
