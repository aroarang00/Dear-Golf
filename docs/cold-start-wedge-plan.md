# 콜드스타트 · 출시 웨지 플랜 (초안)

> 작성 2026-06-29. **가설 묶음**이다 — 숫자는 출발점일 뿐, 시드 결과로 교정한다.
> 핵심 질문: "남이 있어야 가치가 생기는 소셜 골프 앱"을 어떻게 0명에서 띄우나?

## 0. 문제 정의 (왜 이게 제일 큰 리스크인가)
- 모집·크루·DM·친구 = **남이 있어야** 가치. 빈 라운지 = 가치 0 = 첫 사용자 이탈.
- 품질(8/10)로는 못 푼다. 콜드스타트는 **유통·밀도** 문제다.
- 두 개의 레버만 있다:
  1. **단일 플레이어 가치** — 0명일 때도 1명에게 쓸모(이탈 방어 바닥).
  2. **네트워크를 좁게** — "전국"이 아니라 *한 모임*부터 밀도 확보.

## 1. 웨지 한 줄
> **"한 골프 모임(크루)을 통째로 올린다. 스코어 기록이 혼자서도 쓸모를 주고, 크루가 그 안에서 모집·앨범·DM을 즉시 채운다."**

- **네트워크 단위 = 크루.** 전국 동반자 매칭(희박)이 아니라, 이미 서로 아는 한 모임(밀집)에서 시작.
- **come for the tool, stay for the network**: 도구 = 스코어 다이어리/통계/핸디캡(혼자 가치), 네트워크 = 크루/모집.
- **동반자 매칭(모집)은 밀도가 생긴 뒤** 전면에. 처음부터 "동반자 찾기"로 팔면 빈 화면에 데인다.

## 2. 가치 시퀀스 (빈 앱에서도 안 죽게)
| 순서 | 기능 | 0명일 때 가치? |
|---|---|---|
| 1차 바닥 | 스코어 기록·통계·핸디캡·코스 기록·특별한 순간 | ✅ 혼자도 쓸모(기록 쌓일수록 전환비용↑) |
| 2차 밀도 | 크루 앨범·일정·크루지정 모집·DM | ⚠️ 크루 '전원'이 올라야 가치 |
| 3차 확장 | 친구공개/전체 동반자 모집·명예전당 비교 | ⚠️ 지역·시간대 밀도 필요 |

→ **1차로 잡고(이탈 방어), 2차로 묶고(크루 밀도), 3차는 밀도 생긴 뒤.**

## 3. 단계 플랜

### P0 — 출시 전 준비 (1~2주)
- [ ] **핵심 한 줄 확정**: "이 앱은 ___ 하려고 쓴다." (후보: '우리 골프 모임의 스코어·일정·동반자를 한곳에') → 스토어 문구·온보딩·빈 상태 카피를 이 한 줄로 통일.
- [ ] **단일 플레이어 가치 자가검증**: 사장님이 본인 라운드 5개를 실제로 기록해보고 "혼자라도 다시 켜고 싶나?" 점검. 아니면 1차 바닥부터 보강.
- [ ] **첫 시드 크루 2~3개 섭외 약속** 받아두기(사장님이 실제로 닿는 모임: 본인 동호회·회사 골프팀·지인 단톡방).
- [ ] **초대 동선 마찰 제거**: 크루 초대→설치→가입→크루 진입이 카톡 링크 한 번에. 중장년 설치 마찰 점검(카카오 로그인이라 다행).
- [ ] 빈 상태 카피 전수 점검(발견성 감사와 연계).

### P1 — 시드: 크루 3~5개 (첫 4~6주)
- **원칙: 한 크루는 '전원' 올린다.** 부분 가입(8명 중 3명)은 밀도가 안 나서 죽는다. 운영자 1명을 확실히 잡고 그가 전원을 끌어오게.
- 사장님이 **직접 크루 운영자/씨더**가 되어 첫 콘텐츠(공지·앨범 사진·첫 모집)를 채운다. 빈 크루를 보여주지 않는다.
- 각 크루가 **그 안에서 완결**되게: 크루 앨범 + 일정 전파 + **크루지정 모집**(방금 구현) + DM. 외부(라운지 전체)에 안 의존.
- **주간 리듬 만들기**: 주말 라운딩 → 앨범 업로드 → 다음 모집. 이 루프가 자생하는지 관찰.

### P2 — 밀도 → 모집 활성 (6~12주)
- 한 지역/한 모임군에서 활성 사용자가 임계치(예: 같은 권역 30~50명) 넘으면 **친구공개 모집**을 전면에.
- 이때부터 "동반자 찾기"를 메인 메시지로 승격. 빈 라운지 위험이 사라진 뒤.
- 모집 채워짐(확정)률이 밀도 신호 — 낮으면 아직 P1 더.

### P3 — 확장 (자생 구조)
- **크루가 크루를 부른다**: 한 멤버가 다른 모임에도 크루를 만들며 번짐(자연 레퍼럴).
- 명시적 레퍼럴(크루 초대 보상 등)은 자생 신호 확인 후.

## 4. 지표 & Go/Kill
- **활성화**: 가입→첫 스코어 기록률 / 가입→크루 가입률
- **리텐션(바닥)**: 4주 후 재방문 + 스코어 기록 지속(솔로 가치 증거)
- **밀도**: 크루당 주간 활성 멤버, 크루 내 주간 게시·모집 발생 건수
- **매칭**: 모집 생성→확정률
- **★Go/Kill 한 줄**: 시드 크루가 **사장님 push 없이도** 스스로 게시·모집하나?
  - 한다 → 핵심 가치 검증, P2로.
  - 안 한다 → 기능이 아니라 **핵심 용도**를 의심(P0 한 줄 재정의). 기능 추가로 도망가지 말 것.

## 5. 솔로 운영 액션 (현실)
- 첫 3~5 크루는 **수작업**: 1:1 온보딩, 첫 콘텐츠 대신 채워주기, 피드백 직접 수집.
- 자동화·확장은 P2 신호 뒤. 그 전엔 "확장 안 되는 일"을 일부러 한다(do things that don't scale).

## 6. 지금 덜어낼 것 (집중 위해)
- 전체공개 모집(이미 비활성 — 유지). 쇼핑/예약 버튼(법무 전까지 보류 유지).
- 신규 대형 기능 동결. **발견성·빈 상태·초대 동선**만 시드 피드백으로 다듬기.
- 이번 세션 자산(크루지정 모집·모집 보기·댓글 알림)은 P1 크루 루프의 디테일 — 신규가 아니라 **마감**으로 취급.

## 7. 리스크 & 완화
| 리스크 | 완화 |
|---|---|
| 부분 가입으로 크루 밀도 안 남 | 운영자 1명 확실히, '전원 올리기'를 가입 목표로 |
| 솔로 번아웃 | 시드 크루 수를 작게(3~5), 수작업 한도 정하기 |
| 중장년 설치·로그인 마찰 | 카톡 링크 원탭, 온보딩 슬림, 실기기(특히 안드) 검증 |
| iOS/안드 빌드·푸시 미검증 | 출시 게이트(푸시 종단·다계정 모집)부터 — [[release-prep-next-session]] |
| "도구도 약함"이면 바닥 붕괴 | P0 단일플레이어 자가검증을 통과 못 하면 출시 미루고 1차 보강 |

## 8. 한 문장 요약
> **전국에 뿌리지 말고, 사장님이 닿는 한 골프 모임부터 통째로 올린다. 스코어 기록이 혼자서도 잡아두고, 크루가 그 안을 채운다. 모집(동반자 찾기)은 밀도가 생긴 뒤 전면에.**
