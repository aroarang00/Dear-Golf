## 1. 서비스 개요

- 골프 동반자 매칭·라운딩 일정 관리·기록 보관 모바일 앱

### 1.3 가입 연령

### 1.4 데이터 보관

## 2. 핵심 자동 시스템 정책

### 2.1 매너점수 시스템

**구조**
- 0~100점 (신규 70점 시작)
- 4단계 등급: 매너왕(95+) / 좋음(80~94) / 보통(40~79) / 주의(0~39)
- 정확한 수치는 시스템 내부에만 보관, 사용자 UI에는 등급 라벨만 노출
- 앱 내 숫자 노출 없음. 패널티 수치는 약관에만 명시.

**차감 사유 (자동)**

| 사유 | 차감 |
|---|---|
| 노쇼 (신고·소명 후 확정) | -20 (등급 1~2단계 하락) |
| 허위 노쇼 신고 (확정) | -20 (등급 1~2단계 하락) |
| 평가 👎 1명 | 0 (자동 보통 처리) |
| 평가 👎 2명 | -2 |
| 평가 👎 3명 이상 | -3 |

**증가 사유**

| 사유 | 증가 |
|---|---|
| 라운딩 정상 완료 | +2 |
| 평가 👍 | +1 (1명만이라도 가능) |

**2026-05-26 안전 보강**: D-7 이내 참여자 [취소] 버튼 시스템 차단은 약관규제법 제9조(소비자 계약 해지권 박탈) 위반 위험으로 폐기. 대안: 취소 버튼 활성 + 강한 경고 모달 + **매너 -5 자동 차감(일괄, 단계별 X)**. 정지·누적 카운트 없음. D-7 이전 자유 취소(패널티 없음). 티오프 후 미참석은 노쇼 신고 트랙.

### 2.3 신뢰등급 시스템

주최 횟수 누적 + 매너 조건에 따른 사용자 신뢰 표시 배지. 카운트는 라운딩 정상 완료 시 +1, 노쇼·취소는 카운트 없음.

| 등급 | 조건 |
|---|---|
| 신규 | 0회 |
| 브론즈 | 5회+ |
| 실버 | 20회+ |
| 골드 | 50회+ AND 매너 80+ (좋음) |
| 챔피언 | 100회+ AND 매너 80+ (좋음) |
| 레전드 | 200회+ AND 매너 95+ (매너왕) |

**자동 강등**: 노쇼 확정으로 매너 -20 차감 시 매너 등급 하락 → 신뢰도 등급 자동 재계산. 매너점수 회복 시 자동 복귀 가능. 신뢰도 직접 차감 없음.

**카운트 +1 시점**: 티오프 + 5h 시점에 즉시 +1. 이후 노쇼 신고 확정 시 -1 차감 + 매너 -20 + 60일 정지를 트랜잭션으로 함께 처리.

```
1) 마이페이지 → [신고하기] 메뉴
2) 닉네임 입력 (부분 자동완성, 상호작용한 사용자만 매칭)
3) 대상자 프로필 카드 확인
4) 사유 카테고리 (4종):
```
