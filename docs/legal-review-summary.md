## 0. 검토 요청 사항 요약

본 문서는 출시 전 변호사 검토를 위해 Dear Golf 앱의 핵심 정책을 종합한 자료입니다. 다음 사항에 대한 검토를 요청합니다:

1. **이용약관·개인정보처리방침·커뮤니티 가이드라인 초안 작성**
2. **자동 패널티 시스템의 PIPA 적법성** — 특히 2023년 개정 시 신설된 **자동화된 의사결정에 대한 정보주체 권리** (제37조의2)
3. **사용자 간 분쟁 발생 시 플랫폼 책임 회피 면책 조항**
4. **데이터 보관 기간 명시** (PIPA 제21조)
5. **탈퇴/재가입 정책** (banned_users 별도 보존의 적법성)
6. **매너점수 변동 이력 본인 열람권** (PIPA 제35조 — 정확한 수치 비공개 정책 적법성)

핵심 설계 철학: **플랫폼이 법적 책임을 지지 않는 구조를 최우선으로**. 사용자 간 분쟁·결제·매너 판단 등 행위 책임은 사용자·외부 기관으로 명확히 넘기고, Dear Golf는 "장(場) 역할만" 한다는 원칙.

## 1. 서비스 개요

### 1.1 서비스 성격
- 골프 동반자 매칭·라운딩 일정 관리·기록 보관 모바일 앱
- 핵심 기능: 라운지 모집(모르는 사람·친구와 라운딩 매칭), 매너 평가, 신뢰등급 시스템
- 수익 모델: 미정 (출시 후 결정, 결제 기능 없음)

### 1.2 사용자 식별
- **카카오 OIDC 로그인** 기반 (만 19세 이상만 가입 가능)
- Firebase Authentication과 연동 (linkWithCredential 방식)
- 카카오 OIDC sub 식별자만 활용, 카카오 개인정보(이름·전화번호 등) 별도 수집 안 함

### 1.3 가입 연령
- **만 19세 이상 성인만 가입 가능**
- 본인 인증: 1차 카카오 생년월일 동의, 거부 시 PASS·NICE 등 본인인증 SDK
- 만 19세 미만 가입 시도 시 차단

### 1.4 데이터 보관
- 사용자 콘텐츠(닉네임·라운딩 기록·매너점수 등): Firebase Firestore
- 사진(라운딩 사진·신고 근거 사진 등): Firebase Storage
- 푸시 토큰: Firebase Cloud Messaging
- 모든 데이터는 한국 사용자 대상 (해외 출시 계획 없음)
- 항목별 보관 기간: 제17장 참조

## 2. 핵심 자동 시스템 정책

### 2.1 매너점수 시스템

**구조**:
- 0~100점 (신규 70점 시작)
- 4단계 등급: 매너왕(95+) / 좋음(80~94) / 보통(40~79) / 주의(0~39)
- **정확한 수치는 시스템 내부에만 보관, 사용자 UI에는 등급 라벨만 노출**

**차감 사유 (자동, 2026-05-25 단순화)**:
| 사유 | 차감 |
|---|---|
| 노쇼 (신고·소명 후 확정) | **-20** (등급 1~2단계 하락) |

**증가 사유**:
| 사유 | 증가 |

## 3. 사용자 신고차단 정책 (E안 — 무고 손해 0 우선)

### 3.1 설계 원칙

신고 = Dear Golf 팀에 검토 요청만. **즉시 차단 발동 X**. 검토 결과 정당 확정 시에만 양방향 영구 차단. 무고한 사용자가 검토 전에 손해(모집 불가·친구 신청 불가)를 입을 가능성 자체를 0으로 만드는 설계.

### 3.2 신고 진입 동선 (의도적으로 어렵게)

마이페이지에서만 진입 가능. 모집글·프로필 등에서 신고 버튼 제거.

```
1) 마이페이지 → [신고하기] 메뉴
2) 닉네임 입력 (부분 자동완성, 상호작용한 사용자만 매칭)
3) 대상자 프로필 카드 확인
4) 사유 카테고리 (5종):
   - 비매너
   - 허위 프로필
   - 성희롱·욕설
   - 사기 → 경찰 신고 권유 안내 표시
   - **노쇼** → 별도 소명 흐름 (제3-A장 참조)
5) 근거 제출 (필수)
   - 텍스트 진술 (최소 한 줄)
   - 스크린샷 첨부 (선택)
6) 신중 안내 모달
7) [신고하기] → Dear Golf 팀 검토 큐 등록만 (즉시 차단 X)
```

### 3.3 신고 한도
- **월 1건** (남용 방지)
- 일반 차단(5명/일), 콘텐츠 신고(제18장, 무제한)와 별개

### 3.4 검토 흐름

- **시한**: 7일 SLA
- **검토 수단**: deargolf.official@gmail.com 자동 발송 → Firebase 콘솔에서 결과 입력
- **결과 1 (정당)**: 양방향 영구 차단 발동 + 피신고자 추가 제재 + 양쪽 통보
- **결과 2 (허위)**: 신고자에게만 통보 + 신고자 패널티, 피신고자는 끝까지 모름
- **결과 3 (7일 무판정)**: 자동 허위 간주 → 신고 자체 종결, 양쪽 영향 0

### 3.5 허위신고자 패널티 (2026-05-25 정비)

비매너·허위 프로필·성희롱·욕설·사기 카테고리 허위신고 시:

| 누적 (12개월 롤링) | 처벌 |
|---|---|
| 1회 | 매너 -10 + 60일 모집 정지 |
| 2회 | 3개월 모집 정지 |
| 3회 | 영구 모집 자격 박탈 |

**노쇼 신고 허위 패널티는 별도** (제3-A장 참조 — 120일 정지, 2회 영구)

### 3.6 일반 차단 (별개 시스템)

신고와 별개로 사용자 본인이 일방향 차단 가능 (즉시, 해제 가능, 5명/일 한도). 신고자 보호는 이 일반 차단으로 위임.

## 3-A. 노쇼 신고 시스템 (소명 방식, 2026-05-25 신규)

### 3-A.1 설계 원칙

노쇼는 사용자 신고차단(E안, 검토 후 차단)과 다른 **소명 방식**으로 처리. 디어골프는 자료 진위 감정 의무 없이 합리적 판단만 수행 → 시스템 단순 + 팀 부담 최소 + 약관 면책 명문화.

### 3-A.2 처리 흐름

```
1. 노쇼 신고 (라운딩 종료 후 7일 이내)
   피해자 → 마이페이지 → 신고하기 → 노쇼 카테고리
   → 모집 선택 → 참여자 자동 로드 → 대상 선택 → 사유 입력

2. 피신고자 알림: "48시간 내 소명 제출"
   소명 양식: 텍스트 + 사진 첨부 (영수증·결제문자·위치 등)

[Case A] 48시간 내 소명 미제출
  → 자동 노쇼 확정
  → 피신고자: 90일 정지 + 매너점수 -20

[Case B] 소명 제출 → Dear Golf 팀 검토 (48시간)
  • 노쇼 명확 (소명 부실/거짓) → 피신고자 90일 + 매너 -20
  • 허위 신고 명확 (소명 명확) → 신고자 120일 + 매너 -20
  • 소명 애매·증거 불충분 → 양쪽 패널티 X (중립)
  • 48시간 무판정 → 양쪽 패널티 X (중립, 팀 책임)

2회 누적 시 영구 정지 (노쇼·허위신고 각각, 12개월 롤링)

⚠️ 허위 소명 자료 제출 시 (사후 발각) → 즉시 영구 정지 (약관)
```

### 3-A.3 핵심 정책 결정

| 항목 | 결정 |
|---|---|
| 신고 시한 | 라운딩 종료 후 7일 이내 |
| 피신고자 소명 시한 | 48시간 |
| 디어골프 팀 검토 SLA | 48시간 |
| 무판정 처리 | 중립 (양쪽 패널티 X) |
| 신고자 이의 제기 | 없음 (소명 제출만으로 자동 처리) |
| 소명 자료 신고자 공유 | 불가 (개인정보 보호) |
| 매너점수 차감 | 양쪽 -20 (대칭 공정) |

### 3-A.4 약관 조문 초안 (변호사 검토 요청 🔴)

```
제○조 (노쇼 신고 및 처리)
1. 라운딩 종료 후 7일 이내 신고할 수 있습니다.
2. 피신고자는 신고 접수 후 48시간 내 소명할 수 있습니다.
3. 소명 자료는 신고자에게 공유되지 않습니다 (개인정보 보호).
4. 소명 미제출 시 노쇼로 자동 확정됩니다.
5. 소명 제출 시 Dear Golf 팀이 48시간 내 검토하며, 미판정 시 증거 불충분으로 처리됩니다.
6. 노쇼 확정 시 90일 모집·참여 자격 정지 + 매너점수 차감, 2회 누적 시 영구 정지됩니다.
7. 허위 신고 확정 시 120일 모집·참여 자격 정지 + 매너점수 차감, 2회 누적 시 영구 정지됩니다.
8. 허위 소명 자료 제출 시 즉시 영구 정지됩니다.

제○조 (면책)
1. Dear Golf는 신고 접수 및 검토 서비스를 제공하며, 검토 결과의 객관성 및 
   처리 결과에 대해 고의·중과실이 아닌 한 법적 책임을 지지 않습니다.
2. Dear Golf는 제출된 소명 자료의 진위 여부를 감정할 의무가 없으며,
   제출 자료를 기반으로 합리적으로 판단합니다.
3. 신고 처리 결과에 불복하는 경우 관할 수사기관에 별도로 신고하실 수 있습니다.
```

### 3-A.5 가입 시 별도 동의 체크박스 (절차적 정당성 핵심)

```
[ ] 신고 시스템 및 패널티 정책에 동의합니다 (필수)
```

- 일반 이용약관 동의와 **분리된 체크박스**
- 사후 분쟁 시 "본인이 명시적으로 동의" 1차 방어

### 3-A.6 ⚠️ 약관 규제법 제7조 검토 필요

사업자의 고의·중과실까지 면제하는 약관은 무효 가능성 → "고의·중과실이 아닌 한" 단서 포함됨. 변호사 검토 시 추가 무효 가능 조항 확인 요청.

## 4. 강퇴 정책 (전체공개 모집 한정)

### 4.1 적용
- **전체공개(`scope: 'all'`) 모집의 수락된 참여자만** 강퇴 가능
- 친구공개·친구지정 모집은 강퇴 기능 없음

### 4.2 흐름
1. 주최자가 강퇴 → 사유 선택 (비매너 행동 / 허위 프로필 — 2개만, 기타 없음)
2. 즉시 참여 취소
3. 강퇴당한 참여자 통보: "주최자 사정으로 참여가 취소됐어요" (구체적 사유 블라인드)
4. 강퇴당한 참여자: **패널티 없음**

### 4.3 강퇴 남용 방지 (자동, Dear Golf 팀 개입 없음)
- 월 2회까지만 가능, 3회째는 시스템이 차단
- 12개월 롤링 누적 10회 이상: **모집 자격 2개월 정지**

## 5. 매너 평가 정책

### 5.1 자발적 평가
- 라운딩 종료 후 48시간 평가 윈도우
- **평가 강제성 없음** — 자발적 참여만
- 평가 안 한 사람은 자동 "보통(0)"으로 처리

### 5.2 평가 옵션
| 평가 | 변동 | 발동 조건 |
|---|---|---|
| 👍 좋았어요 | +1 | 1명만이라도 가능 |
| 😐 보통 | 0 | (무평가 기본값) |
| 👎 별로였어요 | -3 | **2명 이상** 명시적 👎일 때만 |

### 5.3 익명성
- 평가 결과는 익명 일괄 집계 (Cloud Functions 서버에서만 처리)
- 개별 평가자 정보는 사용자에게 노출 안 됨

## 6. 게스트 정책 (앱 미사용자 인원 — PIPA 완전 회피)

### 6.1 정의
- 앱 미사용자를 주최자가 라운딩 인원으로 등록하는 기능
- 명칭: "게스트" (이전 "외부 동반자" 표현 폐기)

### 6.2 입력 정보 — 없음 (숫자만)
- **이름·성별·연락처 일체 입력 없음**
- 주최자가 "게스트 N명" 숫자만 지정
- **개인정보 처리가 발생하지 않음** → PIPA 적용 대상 외

### 6.3 PIPA 부담 0
- 이름을 안 받으므로 본인 동의 체크박스 불필요
- 자동 삭제 정책 불필요
- 변호사 검토 시 별도 면책 조항 필요 없음

### 6.4 게스트 자동 패널티
- **자동 패널티 시스템 적용 안 함** (앱 계정 없음)
- 게스트 노쇼·취소 → 같이 참여한 앱 사용자가 주최자를 매너 평가에서 자연 평가

## 7. 댓글 정책

### 7.1 권한
- **작성·열람**: 주최자 + 참여 확정자만 (모집 신청자·일반 사용자 불가)
- **삭제**: 본인 댓글만 (주최자도 타인 댓글 삭제 불가)
- **수정**: 불가 (삭제 후 재작성)

### 7.2 자동 비활성
- 티오프 시각 지나면 쓰기 자동 차단, 읽기는 유지

### 7.3 비속어 필터
- 자동 감지 시 업로드 차단 + 안내
- 추가 패널티 없음 (반복 시도자는 신고 시스템으로 처리)

## 8. 탈퇴/재가입 정책 (PIPA 잊혀질 권리 vs 정지 우회 차단)

### 8.1 탈퇴 시 삭제 (사용자 콘텐츠 전부)
- 닉네임·프로필·매너점수·라운딩 기록·다이어리·모집글·참여 이력·댓글·친구 목록·차단 목록·북마크·평가 이력·신고 이력 등 모두 삭제

### 8.2 별도 보존 (정지 우회 차단용)
- 별도 `banned_users` 컬렉션에 다음만 저장:
  - 카카오 OIDC sub (식별자, 개인정보 아님)
  - 정지 사유·기간
- **닉네임·이름 등 개인정보 일체 보존하지 않음**
- 재가입 시도 시 sub 매칭으로 차단

### 8.3 케이스별 처리
| 케이스 | 처리 |
|---|---|
| 정상 사용자 자발 탈퇴 | 전부 삭제, banned_users 추가 X, 재가입 자유 |
| 임시 정지 중 탈퇴 (예: 60일) | 콘텐츠 삭제 + 남은 정지 기간만 banned_users 보존 |
| 영구 정지 후 탈퇴 | 콘텐츠 삭제 + 영구 banned_users 보존 |

### 8.4 진행 중 신고 처리
- B 탈퇴 후에도 신고 건은 처리 진행 (다른 사용자 보호)
- 검토 결과 정당하면 B의 카카오 sub를 banned_users에 추가

### 8.5 사용자 사망 시 계정 처리
- **사용자 사망 시 법정대리인 또는 직계가족이 고객센터 이메일(deargolf.official@gmail.com)로 계정 삭제를 요청할 수 있음**
- 별도 자동 시스템 X, 이메일 신청 → Dear Golf 팀 본인관계 증빙 확인 (사망진단서·가족관계증명서 등) → 수동 삭제
- 일반 탈퇴와 동일 처리 (콘텐츠 전부 삭제 + 정지 케이스라면 banned_users 보존)

## 9. 비용 정산 정책 (Dear Golf 결제 중개 X — 전자금융업 등록 회피)

### 9.1 면제 흐름 (임박 취소·노쇼 사후 면제)
1. 노쇼자/취소자가 동반자들에게 **직접 송금** (카카오페이·계좌이체 등, 외부 처리)

3. 주최자 알림함에 도착 → 외부 확인 후 [면제 승인] 클릭
4. Dear Golf 자동 처리 (정지 해제 + 매너 복구 + 카운트 -1)

### 9.2 Dear Golf 역할 한정
- 면제 승인 UI만 제공
- **결제 중개 안 함, 송금 검증 안 함, 분쟁 정산 안 함**
- 송금 증빙 사진은 사용자 간 참고용 (Dear Golf 검증 X)

### 9.3 약관 명시 필수
> "비용 정산은 사용자 간 직접 처리하며, Dear Golf는 면제 승인 UI만 제공하고 정산에 관여하지 않습니다. 송금 증빙은 사용자 간 참고용입니다."

| **모집글 데이터** | 라운딩 후 1년 자동 삭제 | "내 라운지 활동" 이력 보존 후 자동 삭제 |
| **댓글** | 모집글과 함께 자동 삭제 (라운딩 후 1년) | 모집글 따라감 |
| **매너점수 변동 이력** | 12개월 롤링 | 현재 점수만 유지, 이력은 12개월 후 자동 삭제 |
| **신고 이력** | 처리 완료 후 3년 | 민사 소멸시효 3년 고려 |
| **차단 이력** | 본인이 해제 전까지 | 해제 시 즉시 삭제 |
| **카카오 OIDC 정보** | 회원 유지 기간 | 탈퇴 시 sub만 banned_users 이관(정지 케이스), 나머지 삭제 |
| **푸시 토큰 (FCM)** | 회원 유지 기간 | 탈퇴 시 즉시 삭제 |
| **관계법령 해당 항목** | 법령에서 정한 기간 | 전자상거래법·통신비밀보호법 등 별도 의무 |

자동 삭제는 Cloud Functions 스케줄러로 일별 처리.

## 18. 콘텐츠 신고 시스템 (사용자 신고와 분리)

게시물(모집글·모집 댓글·골퍼코멘트)의 광고/스팸·부적절 콘텐츠를 신고하는 시스템. 사용자 신고와 완전 분리.

### 18.1 두 신고 시스템 분리

| 항목 | 사용자 신고 | 콘텐츠 신고 |
|---|---|---|
| 대상 | 사용자 (사람) | 게시물 |
| 카테고리 | 비매너·허위프로필·성희롱·욕설·사기 | 광고/스팸·부적절 콘텐츠 |
| 진입 | 마이페이지 깊은 동선 | 게시물 옆 가벼운 동선 |
| 결과 | 양방향 영구 차단 + 추가 제재 | 게시물 삭제 + 작성자 누적 |
| 한도 | 월 1건 | **횟수 제한 없음** |
| 허위 신고자 패널티 | 매너 -10 + 60일 정지 등 | **없음** |
| 검토 SLA | 7일 | **3일** |

### 18.2 신고 대상 영역 (우선순위)

| 영역 | 광고/스팸 위험 | 적용 |
|---|---|---|
| **골퍼코멘트** (전체 공개·익명) | **매우 높음** ⭐ | ✅ 메인 |
| **모집글 본문** | 높음 | ✅ |
| **모집 댓글** (참여자끼리만) | 낮음, 사이버 폭력 위주 | ✅ 보조 |
| **다이어리 사진** (친구공개/나만보기) | 거의 없음 | ❌ 제외 (친구 차단으로 처리) |

### 18.3 골퍼코멘트 안전장치
- 신고 3건 누적 시 **자동 임시 가림** (다른 사용자에게 안 보임, 작성자만 보임)
- Dear Golf 팀 검토 후 정당 → 영구 삭제, 허위 → 가림 해제·복구
- 골퍼코멘트 **작성 권한**: 회원만 (만 19세 이상 카카오 로그인, 익명 표시명만 외부 노출)

### 18.4 작성자 자동 제재 (12개월 롤링 누적)

| 누적 | 처리 |
|---|---|
| 5회 | 매너 -5 + 30일 모집 정지 |
| 10회 | **영구 모집 자격 박탈** |

### 18.5 검토 운영
- Dear Golf 팀 이메일(deargolf.official@gmail.com) + Firebase 콘솔
- 신고자에게 별도 통보 X (조용히 처리)
