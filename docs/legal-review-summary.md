## 0. 검토 요청 사항 요약

본 문서는 출시 전 변호사 검토를 위해 Dear Golf 앱의 핵심 정책을 종합한 자료입니다 (최종 갱신: 2026-05-26 D-7 단일선 개편 + 안전망 보강 반영). 다음 사항에 대한 검토를 요청합니다:

### A. 초안 작성 의뢰
1. **이용약관 초안 작성**
2. **개인정보처리방침 초안 작성** (현재 PRIVACY.md는 옛 정책 기반 — 전면 개정 필요)
3. **커뮤니티 가이드라인 초안 작성**

### B. 자동 시스템 적법성 검토 (PIPA 핵심)
4. **자동 패널티 시스템의 PIPA 적법성** — 2023년 개정 시 신설된 **자동화된 의사결정에 대한 정보주체 권리** (제37조의2). 별도 이의제기 절차 폐기 + 소명 절차로 대체한 구조의 권리 보장 충족 여부 (제10장)
5. **매너점수 변동 이력 본인 열람권** (PIPA 제35조) — 정확한 수치 비공개·자연어 안내 정책이 열람권 충족하는지
6. **데이터 보관 기간 명시** (PIPA 제21조) — 항목별 표 + **분쟁 이력 모집글 3년 보관 기준(`hasDispute` 플래그)** 적법성 (제17장)
7. **탈퇴/재가입 정책** — `banned_users`에 카카오 OIDC sub만 별도 보존하는 방식의 적법성 (제8장)

### C. 운영 정책 적법성 검토
8. **D-7 단일선 정책 적법성** — D-7 이내 참여자 시스템 취소 차단·주최자 변경 차단이 약관 규제법상 사용자 자율 제한으로 무효 가능성 여부 (제2.2장)
9. **노쇼 신고 7일 유예 + 신고자 자율 취소 + 재신고 불가** — 약관 자율 vs PIPA·소비자 권리 충돌 가능성 (제3-A장)
10. **신고 시스템 명예훼손·무고 위험** — E안(즉시 차단 X) + 노쇼 7일 유예 모델의 법적 안전성 (제3장 + 제3-A장)
11. **사용자 보호 우선 원칙 — 검토 SLA 자동 면책의 법적 효력** (제12.12) — SLA 초과 시 자동 종결·자동 인용 처리가 운영자 책임 면책 근거로 유효한지
12. **라운딩 인원 변경 시 신청자 권리 보장** (제12.17) — 카카오VX "원천 차단" 모델 대체로 알림+자유 취소 부여가 권리 보장 효력 충족하는지

### D. 면책 조항 적법성 검토
13. **이동·골프장 내 안전사고·라운딩 전·중·후 사고·사기 면책** (제12.3) — 4개 카테고리 면책 조항의 약관 규제법 제7조 적합성 ("고의·중과실 제외" 단서 포함)
14. **서비스 기능 한정 조항** (제12.3-A) — 카카오VX 톤 "모집 기능만 제공, 그 외 책임 X"의 한국 검증 모델 비교
15. **비용 정산 외부 처리** (제9장) — 전자금융업 등록 불필요 확인, 분쟁 시 책임 회피 가능성
16. **저작권·초상권 사용자 책임 면책** (제12.13) — 사용자 업로드 콘텐츠 권리 침해 시 사용자 책임 명시의 효력
17. **개인정보 침해 신고 채널** (제12.14, PIPA 제64조) — 마이페이지 + 한국인터넷진흥원(118) 안내가 의무 이행에 충분한지
18. **관할·준거법** (제12.15) — 한국 사용자 대상 명시 + 대한민국 관할 법원 합의관할

### 핵심 설계 철학

**플랫폼이 법적 책임을 지지 않는 구조를 최우선으로**. 사용자 간 분쟁·결제·매너 판단·이동·골프장 내 사고 등 행위 책임은 사용자·골프장·외부 기관으로 명확히 넘기고, Dear Golf는 "장(場) 역할만" 한다는 원칙. 동시에 **검토 SLA 자동 면책**으로 운영자 측 위험도 사용자 권리 보장으로 회피.

## 1. 서비스 개요

### 1.1 서비스 성격
- 골프 동반자 매칭·라운딩 일정 관리·기록 보관 모바일 앱
- 핵심 기능: 라운지 모집(모르는 사람·친구와 라운딩 매칭), 매너 평가, 신뢰등급 시스템
- 수익 모델: 미정 (출시 후 결정, 결제 기능 없음)

### 1.2 사용자 식별
- **카카오 OIDC 로그인** 기반 (만 19세 이상만 가입 가능)
- Firebase Authentication과 연동 (linkWithCredential 방식)
- 카카오 OIDC sub 식별자만 활용, 카카오 개인정보(이름·전화번호 등) 별도 수집 안 함

### 1.3 가입 연령
- **만 19세 이상 성인만 가입 가능**
- 본인 인증: 1차 카카오 생년월일 동의, 거부 시 PASS·NICE 등 본인인증 SDK
- 만 19세 미만 가입 시도 시 차단

### 1.4 데이터 보관
- 사용자 콘텐츠(닉네임·라운딩 기록·매너점수 등): Firebase Firestore
- 사진(라운딩 사진·신고 근거 사진 등): Firebase Storage
- 푸시 토큰: Firebase Cloud Messaging
- 모든 데이터는 한국 사용자 대상 (해외 출시 계획 없음)
- 항목별 보관 기간: 제17장 참조

## 2. 핵심 자동 시스템 정책

### 2.1 매너점수 시스템

**구조**:
- 0~100점 (신규 70점 시작)
- 4단계 등급: 매너왕(95+) / 좋음(80~94) / 보통(40~79) / 주의(0~39)
- **정확한 수치는 시스템 내부에만 보관, 사용자 UI에는 등급 라벨만 노출**

**차감 사유 (자동, 2026-05-26 D-7 단일선 개편)**:
| 사유 | 차감 |
|---|---|
| 노쇼 (신고·소명 후 확정) | **-20** (등급 1~2단계 하락) |
| 허위 노쇼 신고 (확정) | **-20** (등급 1~2단계 하락) |
| 평가 👎 1명 | **0** (자동 보통 처리) |
| 평가 👎 2명 | **-2** |
| 평가 👎 3명 이상 | **-3** |

**증가 사유**:
| 사유 | 증가 |
|---|---|
| 라운딩 정상 완료 | +2 |
| 평가 👍 | +1 (1명만이라도 가능) |

**※ 취소에 대한 시스템 매너점수 차감은 없음** (2026-05-26 D-7 단일선 개편). D-7 이전엔 자유 취소, D-7 이내엔 시스템적으로 취소 차단(주최자 우천·천재지변 취소만 가능). 못 가는 경우는 댓글 양해 + 매너 평가에서 자연 반영. 티오프 후 미참석은 노쇼 신고 트랙.

### 2.3 신뢰등급 시스템 (2026-05-26 매너 조건 추가)

**카운트는 라운딩 정상 완료 시 +1, 노쇼·취소는 카운트 X**.

| 등급 | 조건 |
|---|---|
| 신규 | 0회 |
| 브론즈 | 5회+ |
| 실버 | 20회+ |
| **골드** | **50회+ AND 매너 80+ (좋음)** |

**카운트 +1 시점 — 낙관적 처리**: 티오프 + 5h 시점에 즉시 +1 (라운딩 종료 추정 시각). 이후 노쇼 신고 가능 기간(라운딩 후 7일) 안에 신고가 자동 확정되면 -1 차감 + 매너 -20 + 60일 정지를 트랜잭션으로 함께 처리. 사용자에게 강등 사유를 명시한 중대 알림 발송.

## 3. 사용자 신고차단 정책 (E안 — 무고 손해 0 우선)

### 3.1 설계 원칙

신고 = Dear Golf 팀에 검토 요청만. **즉시 차단 발동 X**. 검토 결과 정당 확정 시에만 양방향 영구 차단. 무고한 사용자가 검토 전에 손해(모집 불가·친구 신청 불가)를 입을 가능성 자체를 0으로 만드는 설계.

### 3.2 신고 진입 동선 (의도적으로 어렵게)

마이페이지에서만 진입 가능. 모집글·프로필 등에서 신고 버튼 제거.

```
1) 마이페이지 → [신고하기] 메뉴
2) 닉네임 입력 (부분 자동완성, 상호작용한 사용자만 매칭)
3) 대상자 프로필 카드 확인
4) 사유 카테고리 (5종):
   - 비매너
   - 허위 프로필
   - 성희롱·욕설
   - 사기 → 경찰 신고 권유 안내 표시
   - **노쇼** → 별도 소명 흐름 (제3-A장 참조)
5) 근거 제출 (필수)
   - 텍스트 진술 (최소 한 줄)
   - 스크린샷 첨부 (선택)
6) 신중 안내 모달
7) [신고하기] → Dear Golf 팀 검토 큐 등록만 (즉시 차단 X)
```

### 3.3 신고 한도
- **월 1건** (남용 방지)
- 일반 차단(5명/일), 콘텐츠 신고(제18장, 무제한)와 별개

### 3.4 검토 흐름

- **시한**: 7일 SLA
- **검토 수단**: deargolf.official@gmail.com 자동 발송 → Firebase 콘솔에서 결과 입력

- **결과 3 (7일 무판정)**: 자동 허위 간주 → 신고 자체 종결, 양쪽 영향 0

## 3-A. 노쇼 신고 시스템 (소명 방식, 2026-05-25 신규)

### 3-A.1 설계 원칙

노쇼는 사용자 신고차단(E안, 검토 후 차단)과 다른 **소명 방식**으로 처리. 디어골프는 자료 진위 감정 의무 없이 합리적 판단만 수행 → 시스템 단순 + 팀 부담 최소 + 약관 면책 명문화.

### 3-A.2 처리 흐름 (2026-05-26 7일 유예 추가)

```
T+0  라운딩 종료
T+0~7일  ┐ 신고 접수 가능 (시한)
         │ 피신고자 즉시 중대 알림 (당사자 해결 기회)
         │ 신고자 자율 취소 가능 → 종결, 양쪽 패널티 X
         │ 모집창은 티오프 + 24h 노출 후 감춤 (이후 마이페이지에서 접근)
T+7일  자동 확정 (신고 유지 시) → 피신고자 소명 절차 시작
T+7~9일  피신고자 48시간 소명 (텍스트 + 사진)

[Case A] 48시간 내 소명 미제출
```

| 디어골프 팀 문의 경로 (강퇴·콘텐츠 누적) | O | - |

### 11.2 PIPA 자동화된 의사결정 권리 충족
- 이용 정지(권리 제한)는 **사유·기간 명확 통보** + 소명/문의 경로 제공 (제10장 참조)
- 매너점수 차감은 모호 안내 (자존심 보호 + 익명 평가자 보호)

## 16. 검토 우선순위

### 🔴 핵심 검토 필수 (PIPA·약관 규제법·플랫폼 책임)

1. **자동 패널티의 PIPA 적법성** (제2장 + 제10장 + 제11장) — 자동화된 의사결정 권리(제37조의2) 충족 여부. 별도 이의제기 폐기·소명 절차로 대체한 구조의 권리 보장 검토
2. **탈퇴/재가입 정책** (제8장) — `banned_users` 별도 보존(카카오 OIDC sub만)의 적법성
3. **신고 시스템 명예훼손·무고 위험** (제3장 + 제3-A장) — E안(즉시 차단 X) + 노쇼 7일 유예 모델의 법적 안전성
4. **노쇼 신고 자율 취소 후 재신고 불가** (제3-A장) — 약관 자율 vs PIPA·소비자 권리 충돌 가능성
5. **D-7 단일선 정책 적법성** (제2.2장) — D-7 이내 참여자 취소 차단·주최자 변경 차단이 약관 규제법상 사용자 자율 제한으로 무효 가능성 여부
6. **데이터 보관 기간 + 분쟁 이력 3년 (`hasDispute`)** (제17장) — PIPA 제21조 항목별 명시 적법성

## 17. 데이터 보관 기간 (PIPA 제21조) — 카카오VX 모델 + 우리 보강

| 항목 | 보관 기간 | 처리 방식 |
|---|---|---|
| **회원 기본정보** | 탈퇴 즉시 파기 | 닉네임·프로필·매너점수·라운딩 기록·다이어리·친구·차단·북마크 등 |
| **부정 이용자 정보** (`banned_users`) | 정지 기간 동안 (영구 정지는 무기한) | 카카오 OIDC sub 해시 + 정지 사유·기간 |
| **위치정보** | 일회성·즉시 파기 | 골프장 검색·교통·날씨 조회 시점에만 사용 |
| **모집글 데이터 (일반)** | 라운딩 후 1년 자동 삭제 | "내 라운지 활동" 이력 보존 후 자동 삭제 |
| **모집글 데이터 (분쟁 이력)** | 라운딩 후 3년 자동 삭제 | 노쇼 신고·허위신고·강퇴·사용자 신고 등 분쟁 연관 모집글. `hasDispute: true` 플래그 set 시점은 신고 접수 즉시이며, 신고자 자율 취소 시 unset되어 1년으로 환원 |
| **댓글** | 모집글과 함께 자동 삭제 | 일반 1년 / 분쟁 이력 3년 |
| **매너점수 변동 이력** | 12개월 롤링 | 현재 점수만 유지, 이력은 12개월 후 자동 삭제 |
| **신고 이력** | 처리 완료 후 3년 | 민사 소멸시효 3년 고려 |
| **차단 이력** | 본인이 해제 전까지 | 해제 시 즉시 삭제 |
| **카카오 OIDC 정보** | 회원 유지 기간 | 탈퇴 시 sub만 banned_users 이관(정지 케이스), 나머지 삭제 |
| **푸시 토큰 (FCM)** | 회원 유지 기간 | 탈퇴 시 즉시 삭제 |
| **관계법령 해당 항목** | 법령에서 정한 기간 | 전자상거래법·통신비밀보호법 등 별도 의무 |

자동 삭제는 Cloud Functions 스케줄러로 일별 처리.

## 18. 콘텐츠 신고 시스템 (사용자 신고와 분리)

게시물(모집글·모집 댓글·골퍼코멘트)의 광고/스팸·부적절 콘텐츠를 신고하는 시스템. 사용자 신고와 완전 분리.

### 18.1 두 신고 시스템 분리

| 항목 | 사용자 신고 | 콘텐츠 신고 |
|---|---|---|
| 대상 | 사용자 (사람) | 게시물 |
| 카테고리 | 비매너·허위프로필·성희롱·욕설·사기 | 광고/스팸·부적절 콘텐츠 |
| 진입 | 마이페이지 깊은 동선 | 게시물 옆 가벼운 동선 |
| 결과 | 양방향 영구 차단 + 추가 제재 | 게시물 삭제 + 작성자 누적 |
| 한도 | 월 1건 | **횟수 제한 없음** |
| 허위 신고자 패널티 | 매너 -10 + 60일 정지 등 | **없음** |
| 검토 SLA | 7일 | **3일** |

### 18.2 신고 대상 영역 (우선순위)

| 영역 | 광고/스팸 위험 | 적용 |
|---|---|---|
| **골퍼코멘트** (전체 공개·익명) | **매우 높음** ⭐ | ✅ 메인 |
| **모집글 본문** | 높음 | ✅ |
| **모집 댓글** (참여자끼리만) | 낮음, 사이버 폭력 위주 | ✅ 보조 |
| **다이어리 사진** (친구공개/나만보기) | 거의 없음 | ❌ 제외 (친구 차단으로 처리) |

### 18.3 골퍼코멘트 안전장치
- 신고 3건 누적 시 **자동 임시 가림** (다른 사용자에게 안 보임, 작성자만 보임)
- Dear Golf 팀 검토 후 정당 → 영구 삭제, 허위 → 가림 해제·복구
- 골퍼코멘트 **작성 권한**: 회원만 (만 19세 이상 카카오 로그인, 익명 표시명만 외부 노출)

### 18.4 작성자 자동 제재 (12개월 롤링 누적)

| 누적 | 처리 |
|---|---|
| 5회 | 매너 -5 + 30일 모집 정지 |
| 10회 | **영구 모집 자격 박탈** |

### 18.5 검토 운영
- Dear Golf 팀 이메일(deargolf.official@gmail.com) + Firebase 콘솔
- 신고자에게 별도 통보 X (조용히 처리)
